# Edu Tracking

An ASP.NET Core MVC application for managing and tracking educational activities.

## Features

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views

## Prerequisites

- .NET SDK 8.0+
- Visual Studio 2022 or Visual Studio Code
- SQL Server (if applicable)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/edu-tracking.git
```

### Navigate to the project

```bash
cd edu-tracking
```

### Restore packages

```bash
dotnet restore
```

### Build

```bash
dotnet build
```

### Run

```bash
dotnet run --project edu-tracking/edu-tracking.csproj
```

The application will be available at:

```
https://localhost:7115
```
